# Verso

中文写作桌面软件。作品、章节、版本与备份以普通文件保存在本机。

## 功能

- 富文本正文编辑，分卷 / 章节管理，支持拖拽排序
- 大纲、角色设定、伏笔标记、版本历史
- 打字机模式、段落聚焦、水墨晕染打字
- 净字数与平台字数双口径统计，每日写作目标
- 敏感词标记、AI 校对、重复段落查重、发布前体检
- 按平台排版一键复制，支持起点、晋江、番茄
- 导出 TXT / Markdown / DOCX / PDF，导入 TXT / Markdown / DOCX
- 全文检索与批量替换，替换前自动留存快照
- AI 续写、注释指令、润色，可接任意 OpenAI 兼容接口

## 安装

从 Releases 下载 `Verso-版本号-setup.exe`。

## 数据

存放于 `%APPDATA%\Verso\data`，可直接拷贝迁移，卸载不删除。

## 更新

设置 → 关于 → 检查更新。

## 说明

本仓库仅用于分发安装包。
